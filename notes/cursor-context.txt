# CHOP Gene Prediction - Project Context

## Project Overview
CHOP (Chromosome Open Prediction) is a transformer-based gene prediction tool that uses attention mechanisms to identify genes, exons, introns, and coding regions in genomic DNA sequences. The system is designed to handle complex gene structures with biological accuracy.

## Current Working Setup

### Environment
- **Platform**: M4 MacBook Air with 24GB RAM
- **Python Environment**: `chop_env` virtual environment
- **Training Commands**: 
  - CPU: `python train_cpu_only.py --config [config].yaml`
  - MPS: `python train_mps.py --config [config].yaml`
- **Inference Command**: `python inference/predict.py --model [model] --config [config] --input [sequences].fna`

### Data Processing Pipeline
CHOP uses a two-stage data pipeline:

1. **Preprocessing Stage** (`scripts/preprocess_gene_data.py`):
   - Input: Raw genomic FASTA + GFF annotations
   - Output: Normalized gene contexts + adjusted annotations
   - Features: Gene context extraction, strand normalization, coordinate adjustment

2. **Training Stage** (`training/train.py`):
   - Input: Preprocessed gene contexts + annotations
   - Features: Data validation, sliding windows, caching

### Current Optimal Configuration
**File**: `configs/m4_mps_model7M_layer4_head6_seqlen12k_sliding.yaml`
- **Model size**: 7M parameters, d_model=256, 4 layers, 6 heads
- **Sequence length**: 12,288 bp (12k) - optimal memory/coverage tradeoff
- **Sliding windows**: 6,144 bp stride (50% overlap)
- **Training**: MPS acceleration with batch_size=4, accumulate_grad_batches=16

## Model Architecture

### Transformer Design
- **4 layers**: Hierarchical learning from local motifs to gene architecture
- **6 attention heads**: Capture diverse biological patterns
- **12k sequence length**: Balance between gene coverage and memory usage
- **Parameter count**: 7M parameters for optimal performance/memory tradeoff

### Output Classes
- **GeneBoundaryClass**: START, GENE_BODY, END, NO_GENE
- **ExonIntronClass**: EXON, INTRON, INTERGENIC

### Biological Constraints
- **Start codons**: ATG (enforced in loss function)
- **Stop codons**: TAA, TAG, TGA (enforced in loss function)
- **Strand normalization**: All genes normalized to + strand during preprocessing

## Data Formats

### Input Data
- **Genomic FASTA**: Raw genomic sequences with sequence IDs
- **GFF annotations**: Gene and exon annotations with Parent relationships

### Preprocessed Data
- **Gene context FASTA**: Sequences named by gene ID (gene ± 2kb contexts)
- **Annotation TSV**: Coordinates adjusted to gene context coordinate system

### TSV Columns
| Column | Description | Notes |
|--------|-------------|-------|
| sequence_id | Gene identifier | Always matches FASTA sequence name |
| gene_id | Gene identifier | Same as sequence_id |
| gene_start | Gene start (0-based) | Adjusted to context coordinates |
| gene_end | Gene end | Adjusted to context coordinates |
| exon_start | Exon start (0-based) | Adjusted to context coordinates |
| exon_end | Exon end | Adjusted to context coordinates |
| strand | Strand | Always '+' (normalized) |

## Key Technical Features

### Preprocessing Pipeline
- **Gene context extraction**: Extract gene ± 2kb flanking regions
- **Strand normalization**: Convert all - strand genes to + strand with coordinate adjustment
- **Coordinate transformation**: Adjust all coordinates to gene context coordinate system
- **Biological validation**: Filter genes without valid start/stop codons
- **Exon-based codon checking**: Validate start/stop codons from actual exon boundaries

### Training Features
- **Sliding windows**: Process long sequences with overlapping windows
- **Data validation**: Ensure preprocessed data integrity
- **Biological constraints**: Enforce start/stop codon requirements in loss function
- **Memory optimization**: Efficient processing for 24GB RAM systems
- **MPS acceleration**: Native Apple Silicon GPU support

### Inference Features
- **Bi-directional prediction**: Predict on both forward and reverse complement
- **Sliding window reconstruction**: Seamlessly process long genomic sequences
- **Gene boundary detection**: Identify complete gene structures

## Usage Examples

### Data Preprocessing
```bash
python scripts/preprocess_gene_data.py \
    --fasta raw_genome.fna \
    --gff annotations.gff \
    --output-fasta gene_contexts.fna \
    --output-tsv gene_annotations.tsv \
    --flanking-bp 2000
```

### Model Training
```bash
python train_mps.py --config configs/m4_mps_model7M_layer4_head6_seqlen12k_sliding.yaml
```

### Gene Prediction
```bash
python inference/predict.py \
    --model models/checkpoints/final_model.pt \
    --config configs/m4_mps_longer.yaml \
    --input test_sequences.fna
```
