# CHOP Gene Prediction - Updated Project Context

## Project Overview
CHOP (Chromosome Open Prediction) is a transformer-based gene prediction tool that uses attention mechanisms to identify genes, exons, introns, splice sites, and coding regions in genomic DNA sequences. This project has been significantly enhanced to handle extraordinarily complex gene structures found in coral/cnidarian species.

## Current Working Setup

### Environment
- **Platform**: M4 MacBook Air with 24GB RAM (native Python - faster than Docker)
- **Python Environment**: `chop_env` virtual environment
- **Training Command**: `python train_cpu_only.py --config [config].yaml`
- **Inference Command**: `python inference/predict.py --model [model] --config [config] --input data/test_query.fna`

### Data Characteristics (UPDATED ANALYSIS)
- **Sequences**: Multiple coral species datasets in `data/` directory
- **Primary dataset**: `data/GCA_001939145.1.fna` (819MB) with annotations `data/GCA_001939145.1_filtered_tcov0.99_evalue1e-20.gff`
- **Family-wide analysis**: 153,709 genes across 3 coral species
- **Gene complexity**: 99.8% multi-exon genes, average 17.7 exons per gene (vs ~8 in humans)
- **Gene sizes**: 508 bp to 370 kb (mean: 13.9 kb)
- **Most complex genes**: Up to 299 exons in single genes

### Current Optimal Configuration
**File**: `configs/m2_cpu_model4M_layer4_head6_seqlen12k_sliding.yaml`
- **Model size**: 4M parameters, d_model=256, 4 layers, 6 heads
- **Sequence length**: 12,288 bp (12k) - optimal memory/coverage tradeoff
- **Sliding windows**: 6,144 bp stride (50% overlap)
- **Gene coverage**: 83.4% of genes within 24kb (2 sliding windows)
- **Memory usage**: 16.5 GB (safe within 19.2 GB available)

## Species-Specific Biological Insights

### Coral/Cnidarian Gene Characteristics
- **Extreme complexity**: Far exceeds typical eukaryotic gene structure
- **Consistent across family**: 3 species show similar patterns
- **Biological implications**: Highly regulated gene expression, extensive alternative splicing potential

### Sequence Length Requirements
Based on comprehensive CDF analysis of 153,709 genes:
- **2k windows**: 20.2% coverage (original - inadequate)
- **12k windows**: 66.1% single, 83.4% sliding coverage (optimal)
- **16k windows**: 73.7% single, 89.0% sliding coverage (memory prohibitive)

## Model Architecture Rationale

### Biological Pattern Requirements
**Essential attention heads needed** (see symbiodinium-model-design.txt):
- Splice site motifs (GT/GC donors, AG acceptors)
- Start/stop codon contexts
- Exon/intron boundary detection
- Reading frame maintenance
- Long-range gene coordination

### Layer Hierarchy (4 layers chosen)
1. **Local motifs** (3-10 bp): GT, AG, ATG patterns
2. **Contextual motifs** (10-50 bp): Splice contexts, regulatory elements
3. **Structural elements** (50-500 bp): Complete exons/introns
4. **Gene architecture** (500-5000 bp): Multi-exon coordination

## Key Lessons Learned
- **Sequence length is critical**: Gene complexity demands much longer context than typical
- **Memory scaling is brutal**: O(seq_len²) attention requires careful optimization
- **Biological patterns matter**: Need sufficient attention heads for motif diversity
- **Species-specific analysis essential**: Generic assumptions fail for complex organisms
- **Sliding windows enable coverage**: Can handle genes beyond single window limits

- **Memory errors**: Current 12k config should fit in 24GB RAM with 2.7GB safety margin
- **Training instability**: Use gradient checkpointing and lower learning rates
- **Poor predictions**: Ensure proper class indices and intron labeling fixes are applied
